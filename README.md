One picture of food that makes you hungry: a single glistening grilled salmon fillet, charred edges, flaking pink-orange flesh, butter gloss, wisps of steam, a lemon wedge and dill on dark slate, warm golden light. The salmon fills the frame and still reads clearly at 300 pixels across.

## Run it

```sh
python3 main.py
```

`main.py` validates the bundled `entry.png` (whole PNG, at most 1 MiB and 1024×1024) and copies it byte for byte to `/output/entry.png`, so every run produces the identical file.
